AYSUN MOD - Minecraft Java 1.12.2 Forge

Bu paket Aysun Mod'un KAYNAK PROJESİDİR; hazır derlenmiş .jar değildir.
İçerik:
- Aysun NPC ve çağırma yumurtası
- Oyuncuya bakan ve dünyada dolaşan karakter
- Türkçe konuşma mesajları
- Normal sağ tıkla etkileşim metni
- Eğilerek sağ tıklayınca oturma/kalkma (AI durdurma/açma)
- Gönderilen 64x64 skin dosyasının değiştirilmeden kopyası

Henüz bu sürümde bulunmayanlar: özel GUI, yatma/sarılma animasyonları, kıyafet dolabı,
mobilyalar ve çalışan TV. Bunlar sonraki geliştirme adımlarıdır.

GEREKSİNİMLER
- Minecraft Java 1.12.2
- Minecraft Forge 14.23.5.2860
- Java 8
- Gradle 4.x (ForgeGradle 2.3)

DERLEME
1. Projeyi Java 8 ve Gradle 4.x olan bilgisayara çıkar.
2. İnternet bağlantısı açıkken proje klasöründe `gradle build` çalıştır.
3. Başarılı derleme çıktısı `build/libs/AysunMod-0.1.0.jar` olur.

ÖNEMLİ: Bu proje burada Forge bağımlılıklarıyla derlenip Minecraft'ta test edilmedi.
JAR üretildiği veya oyunda kesin çalıştığı iddia edilmemektedir.
